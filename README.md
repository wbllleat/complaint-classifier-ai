# 投诉归档意见AI分类工具

## MVP（v0.1.0）版本
| 优先级 | 功能 | 理由 |
|--------|------|------|
| **P0** | F-01 Excel导入 + F-02 列映射 | 无输入则无输出 |
| **P0** | F-05 分类体系定义（初始硬编码3-5个分类） | 先验证分类可行性 |
| **P0** | F-09 批量分类执行（串行，单线程） | 核心功能 |
| **P0** | F-15 分类标签回写Excel | 核心交付物 |
| **P0** | F-16 基础汇总统计 | 用户最终要的是统计结果 |
| **P0** | F-13 速率控制 + 重试（429处理） | 否则大批量必然失败 |
| **P0** | F-14 结果缓存 | 避免重复调用API，节省成本 |
